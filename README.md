# FibDisp

FibDisp simulates ultrashort-pulse propagation in gas-filled hollow-core fibers/capillaries, including dispersion, attenuation, Kerr nonlinearity, self-steepening, spectral-phase analysis, GDD compression, and parameter sweeps. The web version performs the numerical calculation locally in the browser.
